# Prism 棱镜 · AI 工具接入指南

> 一束光,折射整个 AI 宇宙 —— OpenAI 兼容协议,一行配置接入主流 AI 工具。

## 你的接入信息

在控制台 http://你的域名 注册账号后,在「API 密钥」页面生成一个 `sk-prism-` 开头的密钥,然后按下方说明接入。

| 项 | 值 |
|---|---|
| **API Base URL** | `https://api.your-domain.com/v1` |
| **API Key** | `sk-prism-xxxxxxxx`(控制台生成) |
| **可用模型** | `glm-5.2` `glm-5.1` `glm-5` `glm-5-turbo` `glm-4.7` `glm-4.6` `glm-4.5-air` |

> 协议 100% 兼容 OpenAI,凡是支持「自定义 OpenAI Base URL」的工具都能接入。

## 1. Cursor

**路径**:Settings(⚙️) → Models

1. 关闭上方 `Cursor Tab` 等需要 Cursor 自有模型的功能(可选)
2. 找到 **OpenAI API Key** 区域:
   - `API Key`:填入 `sk-prism-xxxx`
   - 勾选 **Override OpenAI Base URL**
   - `Base URL`:填 `https://api.your-domain.com/v1`
3. 在下方模型列表点 **+ Add Model**,逐个添加:
   ```
   glm-5.2
   glm-5.1
   glm-4.5-air
   ```
   (按需添加,不必全加)
4. 点 **Verify** 验证 —— 显示绿色 ✓ 即成功
5. 回到对话,在模型选择器里选你刚加的 `glm-5.2`

**验证命令**(终端,等同 Cursor 的请求):
```bash
curl https://api.your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer sk-prism-你的key" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5.2","messages":[{"role":"user","content":"hi"}]}'
```

## 2. Continue.dev(VS Code / JetBrains 通用)

编辑 `~/.continue/config.json`:

```json
{
  "models": [
    {
      "title": "Prism GLM-5.2",
      "provider": "openai",
      "model": "glm-5.2",
      "apiBase": "https://api.your-domain.com/v1",
      "apiKey": "sk-prism-你的key"
    },
    {
      "title": "Prism GLM-4.5-Air",
      "provider": "openai",
      "model": "glm-4.5-air",
      "apiBase": "https://api.your-domain.com/v1",
      "apiKey": "sk-prism-你的key"
    }
  ]
}
```

保存后 Continue 侧栏即可选择使用。

1. 打开插件设置,API Provider 选 **OpenAI Compatible**

   - `Base URL`:`https://api.your-domain.com/v1`
   - `API Key`:`sk-prism-你的key`

3. 保存即用

## 5. OpenAI Python SDK

```bash
pip install openai
```

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.your-domain.com/v1",
    api_key="sk-prism-你的key"
)

# 非流式
resp = client.chat.completions.create(
    model="glm-5.2",
    messages=[{"role": "user", "content": "你好"}]
)
print(resp.choices[0].message.content)

# 流式
stream = client.chat.completions.create(
    model="glm-5.2",
    messages=[{"role": "user", "content": "写一首诗"}],
    stream=True
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

## 7. curl / 任意 HTTP 客户端

**非流式:**
```bash
curl https://api.your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer sk-prism-你的key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.2",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

**流式:**
```bash
curl -N https://api.your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer sk-prism-你的key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.2",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": true
  }'
```

**查询可用模型:**
```bash
curl https://api.your-domain.com/v1/models \
  -H "Authorization: Bearer sk-prism-你的key"
```

## 关于 Claude Code / Hermes / OpenClaw 的说明

**判断标准只有一条**:工具是否允许配置「自定义 OpenAI Base URL」。

- **允许自定义**(如 Cursor / Continue / Cline / Aider 等):填入下方三要素即可接入
- **锁定官方源**(如 Claude Code 只能调 Anthropic 官方 Claude 模型):无法接入任何第三方服务,这是工具本身的设计限制,不是你的服务问题

**通用三要素(任何支持自定义的工具都用这套):**
```
Base URL:   https://api.your-domain.com/v1
API Key:    sk-prism-你的key
模型名:      glm-5.2  (或 glm-5.1 / glm-5 / glm-5-turbo / glm-4.7 / glm-4.6 / glm-4.5-air)
```

**接入前通用验证(任何工具都先用这条 curl 测通):**
```bash
curl https://api.your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer sk-prism-你的key" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-5.2","messages":[{"role":"user","content":"ping"}]}'
```
能正常返回 JSON 回复,说明你的 key 和服务没问题,之后在具体工具里填同样的三要素即可。

## 常见问题

**Q: Verify 报错 / 连接失败?**
- 检查 Base URL 是否带 `/v1` 结尾(必须带)
- 检查 API Key 是否以 `sk-prism-` 开头
- 用上面的 curl 命令测试,看具体报错

**Q: 流式输出卡顿?**
- 部分工具默认不开流式,在设置里开启 `stream: true`
- 若经过 Nginx 反代,需确保 `proxy_buffering off`

**Q: 余额不足?**
- 返回 HTTP 402,去控制台充值
- API 调用前可在 `/api/auth/me` 查余额

**Q: 想用多个模型?**
- 在工具的模型列表里把想用的模型 id 都加一遍即可,切换时选不同模型
